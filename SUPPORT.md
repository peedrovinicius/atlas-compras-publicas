# Suporte

## Antes de abrir uma solicitação

Consulte primeiro:

- o README para visão geral e uso rápido;
- `docs/architecture.md` para arquitetura;
- `docs/multidomain-architecture.md` para separação entre domínios;
- `docs/metodologia-anomalias.md` para os sinais estatísticos;
- `docs/qualidade-normalizador.md` para avaliação do normalizador;
- `docs/api-dashboard.md` para API e dashboard.

## Problemas

Use o formulário **Relatar problema** para erros de captura, normalização, benchmark, analytics, API, dashboard ou documentação.

Sempre que possível, informe o comando executado, a categoria envolvida, o comportamento observado e os passos mínimos para reprodução.

## Melhorias

Use o formulário **Propor melhoria** para sugestões técnicas, analíticas, metodológicas ou de documentação.

Mudanças de parser, taxonomia, regra de normalização ou critério de sinal devem declarar explicitamente o impacto em benchmarks e metodologia.

## Segurança

Não publique vulnerabilidades ainda não corrigidas em issues. Siga [SECURITY.md](SECURITY.md).

## Limites

Este repositório não fornece:

- suporte oficial do PNCP;
- parecer jurídico sobre contratações públicas;
- acusação ou conclusão de irregularidade baseada apenas em sinal estatístico;
- garantia de disponibilidade das fontes externas.
